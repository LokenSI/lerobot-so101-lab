# SO-101 office learning evidence and reusable pipeline

This is reviewable staging for the existing public SO-101 repository, not a publication or model release. Copy the scripts and runtime paths into that repository root. Its existing `scripts/so101_pick_place_baseline.py` and `scripts/prepare_so101_sim.py` bootstrap are prerequisites; they prepare `runtime/flux-action-so101-sim` and retain upstream robot/simulator license notices. This package does not confer new rights to model checkpoints or third-party geometry.

Open `runtime/action-training-phase/office/review-portal/index.html` for actual clips and measured training losses. All failed selected cases remain included. Expert demonstrations are privileged scripted IK; their success never establishes learned-policy success. Native RTX clips replay measured MuJoCo poses with physics disabled, and visual walls/colors were changed only for legibility. The overview arms remain small; inspect the separate closeup. Initial CPU preparation manifests retain their original NOT_EXECUTED status, while later native-render reports and `native-capture-audit.json` establish actual execution.

The original matched eight-command and prospective sixteen-command comparisons both measured 0/6 physical task successes. Fresh common-six matched training also measured 0/6; the separately recorded Smol18 recovery-data repair measured 0/2. A familiar training-scene chunk8 control also failed to lift. All failures remain visible; training loss and teacher-forced accuracy do not establish physical success. Same A100, same CPU OSMesa scenes/256 RGB cameras/six-radian state, paired original instructions, remote RNG resets, and independent grader were used. Full fresh model chunks and actual input hashes are retained. Server-synchronized native inference is reported separately from PNG/SSH and host rendering pauses. These models had different training scopes, and ACT uses an explicit task router rather than neural language understanding. GR00T native MIN_MAX decoding clips normalized values; ACT/Smol MEAN_STD decoding is unbounded, so command-limit counts do not compare raw neural-head safety.

Reusable CPU tooling: `python scripts/office_bootstrap_cpu.py --environment .venv-office-cpu`. This installs pinned rendering/numeric tools in a fresh isolated environment; it does not install CUDA, models, credentials or cloud clients. To generate expert demonstrations, use `office_generate.py`; export approved train-only episodes with `office_export_lerobot.py` as LeRobot v3 or GR00T v2.1. Model-specific environments require their official pinned packages recorded in `runtime/action-training-phase/training/source-pins.json`. The stock training/reload scripts and exact modality config are included. Always retain whole scene groups and original source hashes. Radians apply to all six joints including the gripper.

Remote comparison adapters use the portable `office_ssh_transport.py` provider in this staging copy. Supply your own `OFFICE_SSH_TARGET`, `OFFICE_SSH_PORT`, `OFFICE_SSH_KEY`, `OFFICE_SSH_KNOWN_HOSTS`, and `OFFICE_REMOTE_BASE`; host verification is mandatory. No instance/account discovery or task credentials are included. Prepare a fresh frozen contract and a private adjacent execution-config.json using your own source/checkpoint paths; historical contract hashes/checkpoints are provenance and do not silently adapt to new models. The original local API expects the filename `execution-config.private.json`. Existing source scripts are unchanged except the explicitly recorded provider import/base-path relocation in the staged SSH adapters.

The private master suite has 70 office conditions plus a separate 50-case pipe suite. The separate office-only 120-case plan is not master completion. Neither master office conditions nor office sealed trials have been executed for checkpoint selection. See `suites/master-office-coverage-status.json` for unsupported geometry, lighting, ambiguity, sequence and shifted-start conditions.

Original reports are byte-for-byte copies. Absolute original paths are historical provenance; use the copied relative office directory for local files. `portable-manifest.json` records original/staged SHA256 values and provider relocation. Model weights, optimizer files, environments, caches, full RGB datasets, cloud sessions/account data, credentials, private KUKA content and social drafts are excluded. Full native checkpoints remain in the authorized training workspace and are recovered separately, including optimizer/RNG state.
